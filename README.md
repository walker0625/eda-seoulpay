# 💳 SeoulPay Usage Analysis Project

> **서울페이(SeoulPay) 결제 데이터를 활용한 지역 경제 활성화 전략 분석**

## 📖 프로젝트 개요 (Overview)

본 프로젝트는 서울시 지역화폐인 **'서울페이(SeoulPay)'** 의 결제 현황 데이터를 분석하여 자치구별, 업종별 소비 패턴을 식별하고, 이를 바탕으로 지역 경제 활성화를 위한 **데이터 기반의 인사이트**를 도출하는 것을 목표로 합니다.

### 🎯 분석 목표

* **현황 파악**: 자치구별 서울페이 이용률 및 업종별 결제 규모 분석
* **패턴 식별**: 주거 밀집 지역과 상업 밀집 지역의 소비 업종 트렌드 비교
* **가설 검증**: 통계적 기법(T-test, ANOVA)을 활용한 집단 간 소비 차이 검증

## 🛠️ 기술 스택 (Tech Stack)

* **Language**: Python 3.13+
* **Data Manipulation**: Pandas, NumPy
* **Visualization**: Matplotlib, Seaborn, Folium
* **Statistical Analysis**: SciPy (Shapiro-Wilk, Levene, T-test, ANOVA)

## 📊 데이터셋 (Dataset)

서울시 공공데이터 포털에서 수집한 **서울페이 행정동별 업종별 결제현황 (2024.06)** 데이터를 활용했습니다.

* **주요 컬럼**: `서울페이앱분류업종`, `자치구`, `상품권매출금액`, `상품권거래건수`
* **데이터 크기**: 약 25만 건의 결제 트랜잭션 데이터

## 💡 주요 분석 과정 (Key Analysis)

### 1. 데이터 전처리 (Preprocessing)

* 중복된 행정동/업종 데이터를 `groupby`를 통해 자치구 단위로 집계
* `건당금액(Basket Size)` 파생변수 생성을 통한 업종별 객단가 분석

### 2. 탐색적 데이터 분석 (EDA)

* **지역별 매출 불균형**: 상위 3개구(강남, 서초, 성북)가 하위 3개구(금천, 강동, 구로) 대비 약 **3.8배** 높은 매출 기록
* **업종별 트렌드**: '음식점/식음료업'이 압도적 1위이나, 건당 결제액은 '가구/인테리어', '학원' 등 목적성 소비 업종이 높게 나타남
* **소비 패턴**: 원래 취지와 달리 소상공인 지원보다는 구매력이 높은 자치구(부촌)에서의 소비가 활발함

### 3. 확증적 데이터 분석 (CDA)

* **정규성 검정**: Shapiro-Wilk test를 통해 데이터 분포의 정규성 확인
* **평균 차이 검정**:
* **T-test**: 두 집단(예: 특정 업종 간)의 평균 매출 차이가 통계적으로 유의함을 확인 (p-value < 0.05)
* **ANOVA**: 세 개 이상의 집단 간 평균 차이 분석을 통해 그룹 간 분산 차이 검증



## 📝 결론 및 인사이트 (Conclusion)

* **인사이트**: 서울페이의 사용처가 구매력이 높은 강남/서초 지역과 병원/학원 등 고단가 업종에 집중되는 경향을 보임.
* **전략 제언**:
1. **지역 균형 발전**: 사용률이 저조한 자치구(금천, 구로 등) 대상의 추가 캐시백 프로모션 필요.
2. **업종별 타겟팅**: 식음료업 외에 생활 밀착형 업종(편의점, 마트 등)으로 사용처를 확대 유도하여 소상공인 상생 취지 강화.
